## Proyek WS Group
Sebuah proyek dengan tujuan pengintegrasian perangkat telekomunikasi, melakukan penggabungan sensor atau komponen pada dekat PCB perangkat yang memiliki RF tinggi.

Percobaan 1 (G1):
Menanamkan GPS Neo M7 dan melakukan komunikasi via WiFi. Bertujuan langkah awal bila perangkat mengalami pencurian, penukaran perangkat dengan jenis hampir serupa, dan pemberi ID yang direncanakan dapat di integrasi kan pada keberlanjutan perusahaan atau proyek.


Percobaan 2 (R1):
Menanamkan recorder, lalu melakukan perekaman selama satu hari, setelahnya file disimpan dan dilakukan koneksi wifi, nelakukan upload menuju server. Pengujian awal untuk pengetesan hasil suara di area dengan gangguan RF tinggi, yang nantinya di integrasikan dengan AI pada jenis perangkat tertentu

Percobaan 3 (GR1):
Melakukan penggabungan G1 dan R1.
